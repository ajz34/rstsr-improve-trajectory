Readings
--------
- add contig B: 0.83 ins/elem is SUB-SCALAR — the loop is AVX-512
  auto-vectorized end to end (vaddpd %zmm confirmed by objdump of the bench
  binary). IPC 0.27 with 40% L1d misses = purely memory-stalled. The
  contiguous kernel has NO codegen headroom left; it is at the memory-system
  bound (43.7 GB/s vs 39.6 GB/s DRAM triad; the 96 MiB working set is partly
  X3D-L3-resident, hence slightly above DRAM).
- add strided B: 161.6 ins/elem at IPC 5.17 = an instruction mountain
  (three IterLayoutColMajor::next per element + closure + try_into unwrap),
  running a 16 KiB-hop access pattern (a and c stride-2048 on the inner
  axis). Instruction-bound AND pattern-bound; both are fixable by a 2-D
  blocked kernel (probe: 6.8 ms vs 23.2 ms, see kernels_probe).
- add contig A: reproduces T0/T7 exactly (12.79 ins/elem, 8358 faults/iter,
  sys-time-heavy). T0's "12.9 ins/elem = no autovectorization" was an
  artifact of measuring the ALLOCATING variant: the fault/allocator
  instruction stream dominates A, while the kernel itself (B) is vectorized.
