# Integration re-verification — patch 2 (elementwise) on merged master

**Date**: 2026-09-14. Base: `origin/master` = `e835173` (PR #100 squash: argmax
kernels + nanargmin/nanargmax). Patch applied as working tree on branch
`260914-elementwise` (uncommitted at bench time; flipped via `git stash` for
refA passes — final tree state = patch applied, script-asserted).

## Protocol

Same-session paired criterion passes, matching the patch-1 integration
cycle: `refA` = clean master, `cand` = patched tree, alternating within each
pass, 3 passes × {portable, native}. Full `--bench elementwise` suite
(54 benchmarks) per stage; `RAYON_NUM_THREADS=16`; no other load on the
machine. Stages: `paired_bench.sh` (idempotent, resume-marker per stage);
logs `*.log`; tables generated by `make_table.py` from the criterion point
estimates only (its `change:` lines are meaningless under alternating trees).

reproduce.** D3-class cells (cand/refA ratio ranges over 3 paired passes):
